Nuna pendant — live audio

Implements the full reverse-engineered protocol from the Nuna 1.9.1 APK: connects, subscribes to A001/A002/A003, runs the 3-step handshake (HANDSHAKE_REQUEST → HANDSHAKE_RESPONSE → HANDSHAKE_COMPLETED), syncs device clock via SET_TIME, reads STATUS, then enables live audio with CONTROL_REQUEST + SWITCH_RECORD (= the same path the official app uses). Audio frames stream as Opus packets on A003 and are reassembled into a playable .ogg file.
